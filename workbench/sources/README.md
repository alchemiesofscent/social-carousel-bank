# Source Files

Naming convention: `{author}-{section}-{topic}.txt`, lowercase, hyphens.

Examples:
- `dioscorides-1.43-1.63-recipes.txt` — Dioscorides Book 1, chapters 1.43–1.63, perfume recipes
- `pliny-nh-12-13-aromatics.txt` — Pliny Natural History Books 12–13, aromatics
- `plutarch-de-iside-80-kyphi.txt` — Plutarch De Iside et Osiride chapter 80, kyphi passage

When Sean pastes a new source text, save it here with the appropriate name before drafting carousels.
